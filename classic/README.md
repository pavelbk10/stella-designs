# סטלה — אתר מעצבת פנים

אתר HTML/CSS/JS סטטי, ללא צורך בשרת יישומים. לפתיחה: `index.html`.

## מה עודכן
- דף בית מינימליסטי מותאם לנייד, עם לוגו סטלה, ניווט ממוקד, שירותים, גלריה, תהליך ויצירת קשר.
- אין וידאו אוטומטי, אפקטי טעינה, אנימציות או סליידרים בדף הבית.
- עודכנה הזהות הטקסטואלית גם בעמודי המשנה, והתווספה שכבת עיצוב רגועה.

## חובה לפני העלאה לאוויר
1. בקובץ `js/stella.js` הזינו `email`, `phone`, `whatsapp` אמיתיים של סטלה. הטופס פותח וואטסאפ או תוכנת דוא״ל; הוא **אינו שולח טפסים לשרת**.
2. החליפו את תמונות Unsplash בדף הבית בתמונות פרויקטים אמיתיים וקבלו אישור שימוש. הן מוגדרות במפורש כצילומי השראה בלבד.
3. עדכנו טקסט אודות, תחומי שירות והיקף הליווי כדי שיהיו תואמים לשירותים בפועל.
4. בחלק מעמודי המשנה המקוריים נשארו מספרי טלפון לדוגמה, קישורי `#`, תיאורי פרויקטים ועדויות דוגמה. בדקו ועדכנו או הסירו לפני פרסום.
5. עדכנו את כתובת האתר ב-`sitemap.xml`, `robots.txt` ומטא-נתונים לאחר קביעת הדומיין.

## העלאה ל-GitHub Pages
העלו את תוכן תיקיית `ester/` לשורש המאגר (ללא `.git` או `.history`), והפעילו GitHub Pages עבור הענף הראשי.
